# ⚡ Pokédex Interativa

Aplicação web interativa que consome a PokeAPI para buscar informações de Pokémon.

## 🔗 Links

- **Repositório público:** https://github.com/GabrielPaes17/bootcamp2-app
- **GitHub Pages:** https://gabrielpaes17.github.io/bootcamp2-app/

## 🔧 Tecnologias

- HTML5, CSS3, JavaScript (ES6+)
- PokeAPI (REST)

## 🎮 Funcionalidades

- Busca por nome ou número
- Busca aleatória
- Imagem, tipo, altura e peso
- Estatísticas com barras visuais
- Cadeia de evolução clicável
