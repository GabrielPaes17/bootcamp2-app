# ⚡ Pokédex Interativa

Aplicação web interativa que consome a [PokeAPI](https://pokeapi.co/) para buscar e exibir informações de qualquer Pokémon.

## 🔧 Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- PokeAPI (REST)

## 🎮 Funcionalidades

- Busca de Pokémon por nome ou número
- Busca aleatória
- Exibição de imagem, tipo, altura e peso
- Estatísticas de base com barras visuais
- Cadeia de evolução clicável

## 🚀 Como usar

1. Abra o arquivo `index.html` no navegador
2. Digite o nome ou número de um Pokémon
3. Clique em **Buscar** ou aperte **Enter**
4. Ou clique em **Aleatório** para descobrir um Pokémon!
